# Вводные данные от системного инженера (АКСИОМЫ ДЛЯ СИСТЕМЫ)

1. Прерывание [CTRL+C] отправляется только для входа в LOADER, если загрузка пошла не по плану, и для выхода из wizard первоначальной настройки.
2. Таймауты не фиксированные, ориентир — до 10 минут на шаг. Ожидание строится строго по появлению целевых промптов (Expect-логика).
3. Обновление ONTAP выполняется строго через Boot Menu -> Пункт 7 ("Install new software first"). Параметры заливки берутся из входного конфига.
4. В пункте 7 Boot Menu контроллер сам интерактивно запрашивает интерфейс (e0M), IP, маску, шлюз и HTTP URL к образу.
5. Правило парсинга версий: патч-версии отбрасываются до минорной (9.x.любой_суффикс = 9.x).
6. Обновление прошивки и инициализация (9b) выполняются строго ПОСЛЕДОВАТЕЛЬНО (сначала Node A, затем Node B).
7. Кластеризация: команда `cluster create` запускается ТОЛЬКО на контроллере LOADER-A. Controller-B присоединяется к кластеру автоматически.
8. Порядок настройки сети в логах верный: сначала подъем кластера, затем настройка SP и e0M.
